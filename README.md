# Natalie Dayan — Website

A responsive, static multi-page website for Natalie Dayan, M.S., CCC-SLP.

## Publishing

All pages are plain HTML, CSS, and JavaScript. Publish the repository root to any static host (GitHub Pages, Cloudflare Pages, Netlify, or a standard web server). No npm install or build step is required. `index.html` is the homepage. Keep all files in the same directory.

## Content and inquiries

The website includes Speech Therapy, Color Splash, Literacy Lab, Learning Pod, About, Testimonials, and Contact pages. Program inquiries use the existing Google Forms links (maintained in the HTML pages) and open in new tabs. Email and telephone links are available on the Contact page.

Before production launch, confirm program availability, credentials, services, testimonial permissions, and preferred wording with Natalie. Replace illustrated accents with approved real photographs only when ready. Existing domain DNS and hosting configuration are not modified by this repository.

## Quality

Use keyboard navigation and a mobile browser to review layouts and check all external forms prior to publishing. The site respects reduced-motion preferences and includes semantic navigation, page descriptions, accessible focus outlines, and responsive styles.
